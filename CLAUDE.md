# Project

Project Name:
Memory Care System

Purpose:
A web application that helps caregivers manage dementia patients and improve memory recall through personalized photographs.

---

# Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- npm
- ESLint
- Prettier

---

# Coding Standards

- Use TypeScript everywhere.
- Avoid using `any`.
- Prefer functional React components.
- Use server components when possible.
- Create reusable components.
- Keep components under 300 lines.
- Use descriptive variable names.
- Write clean, maintainable code.

# UI Principles

- Accessibility first.
- Large touch targets.
- Minimal cognitive load.
- Consistent spacing.
- Calm design.
- Responsive on desktop and tablet.

---

# Accessibility

- WCAG AA contrast.
- Minimum 24px body text.
- Minimum 70px touch targets.
- Keyboard accessible.
- Screen-reader friendly.

---

# Design Philosophy

The application is designed for caregivers and older adults with dementia.

Never sacrifice simplicity for aesthetics.

Every screen should focus on a single task.

---

# Before Writing Code

Always:

1. Analyze existing code.
2. Reuse components.
3. Avoid duplicate logic.
4. Explain major changes.
5. Keep code scalable.

---

# Never Do

- Don't introduce unnecessary libraries.
- Don't use flashy animations.
- Don't overcomplicate components.
- Don't duplicate code.
